# CVForge (flat layout)

Tailor a CV to a job (pasted text or job URL), find gaps and how to cover them, fix LinkedIn, write a human cover letter, and share a digital CV link. Runs in the browser, works with any LLM.

Files: index.html (app), SKILL.md (portable skill), master-prompt.md (paste prompt), use-with-any-llm.md (setup per tool), sample-output.json (sample).

Deploy: upload all files to a repo root, then Settings, Pages, Deploy from a branch, main, / (root).

Job URL note: fetching uses the r.jina.ai reader. LinkedIn often blocks it; if so, paste the text. MIT licence.
